# SpaceClean Privacy Policy

**Last Updated: September 3, 2026**

SpaceClean ('we', 'our', or 'the application') is a 100% free and open-source local desktop utility created by Aneesh Gupta. We respect your privacy and are committed to complete transparency.

---

### 1. Offline & Local-First Processing
SpaceClean operates 100% locally and offline on your computer. All disk scanning, file size metrics, directory tree structures, and MD5 hash calculations are computed strictly in your system's local memory.

### 2. No Data Collection or Telemetry
- SpaceClean does NOT collect, transmit, store, or share any personal information, file paths, file contents, filenames, system metrics, or hardware identifiers.
- SpaceClean contains zero analytics SDKs, zero telemetry trackers, and zero behavioral tracking scripts.

### 3. Network Access & External Services
- **Offline Operation**: SpaceClean does not require an active internet connection to scan drives, calculate hashes, preview files, or perform cleanup.
- **VirusTotal Scanner**: If you explicitly choose to check a suspicious file via the Threat Detector, the application opens a standard web browser lookup to VirusTotal's public lookup with your direct consent. No files or personal data are uploaded in the background.

### 4. File Safety & Operating System Protection
- SpaceClean protects critical operating system binaries and protected kernel files from deletion.
- All delete actions default to moving files into your operating system's native Recycle Bin / Trash with full restoration support.

### 5. Open Source Transparency
